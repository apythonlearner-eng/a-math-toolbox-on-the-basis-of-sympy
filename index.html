📱 构建 APK (Android / HarmonyOS)

方式一：PWA Builder（推荐，无需 SDK）

  1. 将此 HTML 文件部署到任何 HTTPS 服务器（或 GitHub Pages）
  2. 访问 pwabuilder.com
  3. 输入部署后的 URL，点击 Start
  4. 选择 Android → 下载生成的 APK / AAB 包
  5. 直接侧载安装到手机

方式二：Android Studio（需要 Android SDK）

  1. 打开 Android Studio → 新建项目 → Empty Views Activity
  2. 将本项目中的 HTML/CSS/JS 内容全部复制到 app/src/main/assets/index.html
  3. 修改 MainActivity.kt：
class MainActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    val webView = WebView(this)
    webView.settings.javaScriptEnabled = true
    webView.settings.domStorageEnabled = true
    webView.settings.allowFileAccess = true
    webView.loadUrl("file:///android_asset/index.html")
    setContentView(webView)
  }
}

方式三：HBuilder（HarmonyOS / 鸿蒙）

使用 HBuilder 的 WebApp 打包功能，导入此 HTML 文件， 选择 Android 打包 → 填写包名 → 生成 APK。 支持直接在鸿蒙设备上安装运行。

⚙️ 技术栈

  • Pyodide + SymPy — 离线符号计算引擎
  • KaTeX — LaTeX 公式渲染
  • Chart.js — 函数绘图 + 数据可视化
  • PWA Service Worker — 离线缓存 + 可安装到桌面
  • localStorage — 自定义公式持久化保存
  • 100% 客户端运算，无需网络（首次加载后）
